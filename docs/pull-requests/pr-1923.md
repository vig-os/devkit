# [PR 1923](https://github.com/vig-os/devkit/pull/1923) docs(rfcs): default every CI lane to SMALL in site-agnostic ADR

## Description

Amends the accepted `docs/rfcs/ADR-site-agnostic-projects.md` so the default lane map puts **every lane on SMALL**. LARGE and XLARGE have no default lane and are reachable only through the already-accepted `DEVKIT_CI_LANE_SIZES` override (decision (b)-1, unchanged). Owner decision of 2026-10-26.

Why: self-hosted pools usually hold far fewer large runners than small ones (e.g. SMALL ≤ 4–6, LARGE ≤ 2, XLARGE ≤ 1 per org). With `lint`, `test`, `extension` and `release-test` on LARGE, one PR fills every LARGE slot while a second PR queues and the small slots sit idle. Dev-shell realisation is mostly a binary-cache substitution, so those lanes are light.

## Changes Made

- §5: single SMALL row for all lanes; LARGE/XLARGE rows are override-only; rationale paragraph replaces the "both are LARGE" sentence.
