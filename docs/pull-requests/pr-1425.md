# [PR 1425](https://github.com/vig-os/devkit/pull/1425) feat: synthesize bot changelog entries at release time

## Summary

Replaces the per-PR Renovate/adoption changelog pipeline with release-time synthesis (Closes #1423).

- **New `synthesize-bot-changelog`** (vig-utils): enumerates merged bot PRs since the last stable tag from git history, fetches metadata via `gh api`, and regenerates a `#### Dependencies` block under `### Changed` — **net delta per dependency** (earliest `from`, latest `to`, all PRs cited; zero-delta disappears), **lock-file-maintenance rollups per ecosystem** (previously skipped entirely — verified gap in devkit #1315/#1369 and consumers), and **adoption entries coalesced to the shipped devkit version**. The block is the tool's only owned region, rebuilt wholesale each run — idempotent by construction; hand-written entries are never touched.
- **Wired at the two dispatch points that own changelog mutation**: `prepare-release.yml` (before the content gate and the freeze, so the entries ride the freeze commit) and the finalize pass (`release.yml` root / `release-core.yml` scaffold, final kind only, before the date stamp). A bot PR merged into the release branch mid-train is reachable from HEAD at finalize, so it cannot ship unchronicled; candidates stay changelog-neutral.
- **Deleted** `renovate-changelog-build.yml` + `renovate-changelog-commit.yml` (root + scaffold), their sync-manifest entry, zizmor baselines, and preset exclusions; retired via the #1348 retired-paths manifest (1.8.0). Bot PR branches no longer receive changelog commits → concurrent Renovate PRs stop conflicting on `## Unreleased`, Renovate's `rebaseWhen: conflicted` self-rebase works again (the bot author was never in `gitIgnoredAuthors`, so it was dead wiring), and the double CI run per bot PR disappears. The latent release-branch bug (bot PR based on `release/**` inserting into the empty post-freeze Unreleased) dies with the pipeline.
- **Scaffold cut contract**: the Unreleased content gate moves from the host-only validate job into the toolchain-capable prepare job (still ahead of the freeze) so a train whose only content is bot PRs passes; `tag-prefix` threads through for prefixed consumer tag schemes.
- **`just changelog-preview`**: read-only preview of the pending block (root + scaffold).
