# [PR 1943](https://github.com/vig-os/devkit/pull/1943) feat: enforce env-only endpoint configuration

## Description

Enforce ADR §10's env-only configuration rules with default-on hooks limited to shell, dotenv, Python, YAML, TOML and JSON. Literal endpoints and AWS credentials fail with file/line diagnostics that omit values; documentation files, variable/command/template references, empty values, reserved hosts and explicit same-line pragmas pass.

## Changes Made

Add the vig-utils CLI, Nix consumer/check definitions and both portable configurations. Language tags select source files; a companion filename filter includes `.env` and `.env.*` files that pre-commit does not tag. Shell/dotenv use a physical-line assignment scanner shared with the parse-failure fallback: assignment words at statement boundaries are checked, quoted echo arguments stay inert, and pragmas apply to the finding's actual line. Template expressions are references in every format and in fallback scanning. YAML compose environment lists are checked. Other parse/encoding failures emit one notice and scan line-by-line. Document pragma/path exceptions and upgrade behavior in the package README and migration guide.
