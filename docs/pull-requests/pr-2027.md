# [PR 2027](https://github.com/vig-os/devkit/pull/2027) fix(install): make dry-run offline and probe-free

## Description

Make `install.sh --dry-run` fast and deterministic offline. A timestamped trace reproduced a 12.857 s dry run, including 12.814 s in `podman info`, exceeding the existing 10 s test timeout.

## Changes Made

- Discover dry-run runtimes through PATH without daemon probes; explicit flags still win.
- Defer GitHub default-branch lookup and remote latest release resolution; retain local checks and pins.
- Explain deferred checks in help and output. Add PATH-shim regression coverage for all four modes, rejecting network tools and runtime invocation.
- Show unresolved direnv releases as `<latest-release>` placeholders; explain PATH-only runtime selection and possible fallback on a real run.
- Document `--preview` for resolved releases and runtime health, and keep direnv output free of runtime-health disclosures. Pin the container deferred-checks disclosure in regression tests.
- Keep the 10 s timeout unchanged. Exercise remote release resolution through preview, preserving success and failure coverage.

## Changelog Entry

- **Offline, probe-free installer dry runs** ([#2021](https://github.com/vig-os/devkit/issues/2021))
