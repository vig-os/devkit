# [PR 1838](https://github.com/vig-os/devkit/pull/1838) docs: point Rust adopters at the Rust pack instead of a bare compiler

## Description

The adopter docs never led a Rust consumer to the Rust pack, and `docs/MIGRATION.md` actively steered them away from it: it called `rust` an unshipped candidate and recommended `extraPackages = [ pkgs.cargo pkgs.rustc ]`. This PR fixes both passages, adds a Rust section the scaffold can link to, and has the scaffold print that link when a Rust repo's preserved files bypass the pack.

**Stack 4/6** for #1833. Base: #1837 (`feature/1496-rust-cold-adoption-entry`).

## Type of Change

- [x] `docs` -- Documentation only
- [x] `feat` -- New feature (the scaffold notice)
- [x] `test` -- Adding or updating tests

## Changes Made

- `docs/MIGRATION.md`
  - "Adding tools the image does not ship": Rust goes to the pack and C/C++ to `native`. The `extraPackages` example keeps only genuinely ad-hoc tools.
  - "The native-build contract": lists the modules that actually ship (`native`, `node`, `docs`, `guardrails`, `rust`), with `rust` used through `mkRustProject`.
  - New **"Rust projects: the Rust pack"** section: the check table; the new-repo path (`nix flake init -t #rust`, then `install.sh`) and what gets seeded; porting a repo scaffolded before it was Rust (pointers to `assets/flake.d/rust.flake.nix` and the cargo recipes); `toolchainHash` pinning; `sandboxExcludes` (#1834); the base tool configs and advisories outside the sandbox.
  - "Declared project languages" names the new Rust seeds.
- `README.md` (via `docs/templates/README.md.j2` + `just docs`) and `docs/SOLO_ADOPTION.md` link to the section.
- `assets/init-workspace.sh`: `notice_rust_pack_bypass`. In a Rust repo, it prints a notice when a **preserved** `flake.nix` doesn't use `mkRustProject`, or a **preserved** `justfile.project` never runs cargo. Each notice names the gap and links the MIGRATION section. It stays silent on a fresh scaffold, where #1496's seeds already landed. This is the issue's "print a notice when `DEVKIT_LANGUAGES` gains `rust`", scoped to the case that still needs it now that #1496 seeds automatically.
