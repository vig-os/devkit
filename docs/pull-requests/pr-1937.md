# [PR 1937](https://github.com/vig-os/devkit/pull/1937) feat(ci): resolve fork-safe runner classes and lanes

## Description

Resolve runner classes from GitHub variables with the ADR fork predicate enforced inside the action. Migrate scaffolded CI to class and lane outputs while preserving the deprecated SMALL alias for existing callers.

## Changes Made

- Validate each class variable as one label; resolve fork → variable → legacy key → hosted default, with variables winning over the key.
- Pass only scalar PR context fields; validate ASCII labels independently of locale and compare repository names case-insensitively.
- Export runners and runner-sources; every lane defaults to SMALL. Pass the extension lane through the existing reusable input.
- Execute the action Bash in tests for all classes and sources, malformed labels, whitespace, independent fallback, and fork payload variants. Pin workflow routing and forbidden triggers.
