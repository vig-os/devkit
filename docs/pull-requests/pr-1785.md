# [PR 1785](https://github.com/vig-os/devkit/pull/1785) docs(rfcs): record turnkey publish-lane ADR

## Summary

Records the decision from the publish-lane spike #1769 as `docs/rfcs/ADR-publish-lanes.md` (status: **proposed**; flip to accepted on merge).

- **One managed, top-level `publish-release.yml`**, with a job per channel gated on a new `DEVKIT_PUBLISH` declaration. Each job's body is a devkit composite action. crates.io, PyPI and npm Trusted Publishing bind to the caller workflow filename and none accepts reusable workflows, so **the filename is frozen** by this ADR.
- **Ownership split:** devkit manages the publish mechanics; the repo owns the build (`just dist-*`) and the one-time registry registration.
- **Release seal** as the first job of `promote-release.yml`: refuses to undraft a Release with unattested assets, and adds an attested `SHA256SUMS`.
- **OCI** is the one reusable-workflow exception (no registry Trusted Publishing; cosign identity binds to the called workflow). **Nix** is reclassified as CI infrastructure.
- A per-channel verdict and prerelease matrix, verified 2026-09-29 against primary sources (per-channel reviews on #1770–#1776).

## Scope

Docs only; no behaviour change. No `CHANGELOG.md` entry: the ADR ships nothing a consumer can see. Each implementation issue (#1777–#1784, #1748) carries its own entry when it lands.
