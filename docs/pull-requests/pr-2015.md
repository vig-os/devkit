# [PR 2015](https://github.com/vig-os/devkit/pull/2015) feat(docs): add an offline Typst house-style package

## Description

Documents opting into the docs module can import `@local/devkit-docs:0.1.1` offline and apply `#show: devkit-document.with(...)`. The neutral house style supplies document layout, booktabs tables, captions, and reusable components. Branding comes through parameters. The original 0.1.0 import remains available.

## Changes Made

- Supply A4 layout, built-in fonts, a type scale, optional title metadata, running titles, page totals/revision stamps, captions, callouts, revision history and document references. Preserve built-in names and require the show-rule namespace form.
- Preserve spanned cells and explicit header positions/repeat/level settings. Paginate long table figures with repeated headers. Plain-table opt-outs use cell metadata, so user labels and references remain usable. Nested plain tables do not opt out an enclosing ordinary table; native defaults and header positions/settings are covered.
- Honor resolved table stroke/inset overrides, including set and show-set rules. Export `booktabs-table` for an explicit custom inset, including the native 5 pt default. Document the limits of distinguishing explicit native defaults from omitted fields.
- Reject absent, empty, whitespace-only and hidden/zero-width captions. Accept reference-only, citation, styled, contextual, smartquote, show-rule, image and math captions; walk child/body/children and accept opaque elements.
- Wrap docs Typst and Tinymist to compose consumer package paths, the devkit registry and standard data-dir packages. Hooks and recipes share the wrappers. Preserve font isolation and stable dependency inputs after temporary registry cleanup. Accept both spaced and equals forms of deps options and rewrite JSON, Make and zero output in files or on stdout. Forward SIGHUP/SIGTERM/SIGINT and remove the union after child exit. Rewrite produced dependencies for every child exit status, including failed compilation and signal termination, and update symlink targets without replacing their links.
- Lock package contents by version, retain the initial 0.1.0 source alongside 0.1.1, verify both imports offline, hash all vendored preview packages, and check retained versions against an independent release ledger. Document that the guard validates a single-commit snapshot and does not enforce append-only Git history. Exclude only the injected local root LICENSE from content hashes. Vendor licensed fletcher/CeTZ dependencies unchanged.
- Check real PDF text/positions/fonts and SVG rule thicknesses. Kill twenty-one mutants, including all seven identified in round three and S1/S2/S4/S8/S9, and count any regression exception as a failure.

## Additional Notes

Make output is preserved verbatim when a resolved package root contains CR, LF or backslash; JSON and zero are preferred for those roots. Artifact I/O failures preserve the child exit status and the native artifact, with a stderr diagnostic. Dependency stdout is buffered until child exit; ordinary stdout streams normally. The release ledger checks only a single-commit snapshot; editing it can bypass removal detection, including across commits. The append-only policy requires review. Consumer paths take precedence over devkit, then data-dir packages; same-named package precedence is tested through all tool paths.

Plot/glossary rendering, slides and content guards remain separate later phases under #1994. Figure lettering has a 7 pt minimum in the type scale; arbitrary lettering enforcement belongs to those content guards. Numeric helpers do not parse, round or align decimal separators. No merge or workflow dispatch is part of this PR.
