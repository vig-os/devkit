# [PR 1940](https://github.com/vig-os/devkit/pull/1940) feat: extend GitHub App provisioning for organizations and Nix

## Description

Extend GitHub App provisioning to store organization secrets with selected-repository visibility, expose a Nix flake app, and report the correct terminal state after a rejected callback.

### Modifiers

- [ ] Breaking change (`!`)

## Changes Made

- Normalize comma-separated repository names before provisioning and reject `--repos` without `--org-secret`.
- Add `--org-secret --repos` with organization-owner validation and mutual exclusion with `--no-secrets`; credentials stay on stdin and subprocess output stays captured.
- Expose `nix run .#app-provision` through the existing vig-utils package.
- Preserve callback replay protection while showing “This provisioning run has ended” after rejection or failure.
- Document selected-repository secrets, the flake entry point, and a SHA-pinned workflow recipe that masks the App token and appends to existing `NIX_CONFIG`.

## Changelog Entry

### Added

- **GitHub App organization secrets and Nix entry point** ([#1915](https://github.com/vig-os/devkit/issues/1915))
  - Store App credentials as organization secrets with selected-repository visibility using `--org-secret --repos`
  - Run provisioning through `nix run .#app-provision` and document masked App tokens appended to existing Nix configuration
  - Show a terminal-state page for callbacks after a rejected or failed provisioning attempt
