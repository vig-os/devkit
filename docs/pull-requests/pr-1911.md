# [PR 1911](https://github.com/vig-os/devkit/pull/1911) fix(scaffold): render managed docs from manifest settings

## Description

Fixes #1910. Managed `SECURITY.md` and `docs/COMMIT_MESSAGE_STANDARD.md` describe the consumer manifest after scaffolding and upgrades. Disabling scanning removes CodeQL/Scorecard promises and accepted findings; disabling Renovate removes its monitoring claim. Refs wording and exemptions use the same resolved list as the validators, including explicit-list precedence and custom types.

## Changes

- Preserve default document bytes and the issue-less branch rule for exempt types.
- Remove the optional-Refs cross-reference when every type requires Refs; retain inline code formatting in rendered bullets.
- Fail explicitly before splicing when either Exemptions anchor is missing or invalid.
- Document managed rendering in the migration feature/key reference; add ADR metadata, feature audit, and rejected alternatives.
- Keep both files managed with normal Scaffold Drift verification.
