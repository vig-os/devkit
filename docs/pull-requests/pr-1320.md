# [PR 1320](https://github.com/vig-os/devkit/pull/1320) docs(release): document finalize-restart point of no return and tag tombstones

## Description

Lesson from the 1.5.0 ghost: org-enforced release immutability tombstones the tag name of any published-then-deleted release. `devkit-smoke-test`'s `1.5.0` became permanently unusable after a finalize restart deleted its published release, forcing the fully validated train to re-release as 1.5.1. This PR captures that lesson in `docs/RELEASE_CYCLE.md`.

## Type of Change

- [x] `docs` -- Documentation only

## Changes Made

- New policy bullet in **Immutable releases, tag rulesets, and forward-fix policy**: deleting a *published* release permanently tombstones its tag name (`GH013`); drafts never tombstone.
- New recovery-procedures subsection **Restarting a Finalized Release — the Point of No Return**: finalize restarts are cheap only while every release object in the pipeline (devkit **and** `devkit-smoke-test`) is still a draft; once smoke-test publishes its final, the version is committed — restarting means burning it (re-cut as next patch). Includes a pre-restart `gh release view --json isDraft` check for both repos.
- Changelog entry under `## Unreleased` → Changed (mirrored to `assets/workspace/.devcontainer/CHANGELOG.md` by sync-manifest).
