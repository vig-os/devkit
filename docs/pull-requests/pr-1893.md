# [PR 1893](https://github.com/vig-os/devkit/pull/1893) feat(ci): add soft main guard reusable workflow

## Summary

Adds `.github/workflows/main-guard.yml`, a reusable (`workflow_call`) alert-only workflow: when a commit reaches the guarded branch without belonging to a merged PR it opens (or comments on) one `main-guard` issue. It never reverts, force-pushes or fails the caller. Meant for private repos on the Free plan, where rulesets are unavailable. Caller snippet and behaviour notes: `docs/MAIN_GUARD.md`.

## Verification

- `actionlint` and `yamllint` clean; `ruff check`/`format` clean on the test file.
- `pytest tests/test_main_guard.py`: 13 passed. The tests execute the workflow's real `run:` script against a fake `gh` (merged PR silent, direct push opens one issue, open issue gets a comment, unmerged/other-base PR not counted, lagging commit→PR index retried, ignored author, new-branch/force-push, other-branch push).
- Not run: the repo's full pre-commit and test suites (no network for the dev shell where this was written), and no live run against a real push yet.
