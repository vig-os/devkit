# [PR 2014](https://github.com/vig-os/devkit/pull/2014) feat(glossary): discover candidates and refine terminology checks

## Description

Document authors can review unregistered terminology with `glossary-candidates` and `just glossary-candidates`. Advisory JSON lines provide locations, per-file counts, original-source context and the closest canonical term with a similarity score. Candidate discovery subtracts registered names, aliases and part numbers case-insensitively.

The blocking terminology scan preserves code boundaries: backticks become spaces, so code-adjacent plurals and prefixes cannot hide violations. Registered occurrences protect exact, sentence-case and title-case forms unless an explicit casing rule forbids a derived form; ALLCAPS forms require explicit line suppression. Protection applies when a registered span crosses an edge of the forbidden hit or contains it; a registered word contained inside a forbidden phrase does not disable that rule.

## Changes Made

- Discover title-case phrases, CamelCase, part numbers and ALLCAPS acronyms from tracked Markdown/Typst sources. Join across single line breaks while respecting block/name-line boundaries, trim stopwords at both ends, and retain joined names alongside conjunction splits (overridable with `--allow`).
- Filter headings, Markdown table headers, links/URLs, backtick code, underscore identifiers, citations, YAML frontmatter, labeled signatures, Typst strings/link labels, common acronyms and numeric standards.
- Add case-insensitive `--stopwords` and `--allow` controls; allow takes precedence and can restore standards prefixes such as EN.
- Preserve original-source offsets/context and line breaks through masking and markup removal. Report unreadable sources and continue scanning, with correctly named diagnostics.
- Cache nearest-term results across files and use difflib upper-bound prefilters before full comparisons, preserving scores and lexical tie order. Include reproducible repeated-name and distinct-name benchmarks.
- Reject dead rules; protect exact, sentence-case and title-case canonical/alias spans across simple emphasis; retain the longest overlapping forbidden rule and earliest tie. Expand brace alternatives before source-pathspec splitting and warnings.
- Document candidate triage: synonym of X → use the canonical term; new term → add it to glossary.yaml in this PR. Discovery stays advisory with no blocking hook.
