# [PR 1866](https://github.com/vig-os/devkit/pull/1866) fix(ci): give resolve-toolchain sparse checkout its own path

## Description
resolve-toolchain's sparse checkout occupied the workspace root, which later jobs reuse on a persistent self-hosted runner (their checkout never re-materializes the tree). The sparse clone now lives in `.devkit-resolve` in all 7 managed workflows that have the job; the `resolve-toolchain` action gains a `working-directory` input and ci.yml's gate steps run from the new path.
