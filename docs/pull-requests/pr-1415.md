# [PR 1415](https://github.com/vig-os/devkit/pull/1415) test: prune and simplify the test suite (#1413)

## Summary

Implements #1413: prunes the test suite of tests that cannot fail, duplicate coverage, and copy-paste accretion, and consolidates the accreted clusters — with zero loss of distinct failure-mode coverage. Work packages WP1–WP4 of the issue are complete; WP5 (runtime fixtures) is deferred as the issue marks it optional.

**Net: +2,719 / −7,303 lines across 68 files (−4,584 net); ~300 test functions removed or folded.**

### WP1 — wiring & correctness
- Broken `just test-validate-commit-msg` recipe dropped (tests live in vig-utils); stale `test-vig-utils` recipe comment fixed; TESTING.md / tests/README.md rewritten to match reality.
- `test_flake_hooks.py` + `test_flake_services.py` now run in CI (new Project Checks step; PoC boot stays local-only); dev-shell `-k` selection widened to the fixture-driven contracts; dead `suite: utils` step removed from the test-project action; Project Checks timeout 10 → 25 min.
- Fixed the malformed negative assertion in `test_workflow_private_repo_guard.py` (missing quote made it unable to fail) and dropped its cancelled-tolerance (see #1414 for the scaffold-side parity gap this surfaced).
- Both hardcoded action-pin SHAs replaced with shape checks — Renovate bumps no longer red these tests.

### WP2 — cannot-fail tests
Deleted or rewrote every test that could not fail: inline re-implementations of `docs/generate.py` (rewritten through the real functions, closing 3 previously-untested branches), skip-on-failure and trivially-true-disjunct tests in `test_integration.py` (incl. `TestHostGitSignatureSetup`, the podman pass-or-skip family, ~25 unreachable "older template" guards now hard asserts), the order-dependent `TestVersionCheckInitWorkspace`, the bats `prune_mode` self-test cluster, and the constant-mirror / undetectable-claim tests in vig-utils. The whole-word agent-name fingerprint case in `test_validate_commit_msg.py` is now genuinely exercised (it was unreachable behind the Co-authored-by pattern).

### WP3 — duplicates
Every deletion names its surviving twin (see the issue checklists): version-check exact dupes, installed/version pairs, grep-tests shadowed by behavioral e2e siblings in bats, the vig-utils CLI layer collapse (one subprocess layer + the one handler with real logic), scaffold-run-paying duplicate trunk assertions, and the install.sh dry-run dedup onto the bats harness.

### WP4 — consolidation
- `clean.bats` rewritten from 41 line-greps to 8 behavioral tests driving the real script through a logging podman stub (failure-provability spot-checked).
- Version-check feature: 8 classes → 2 (`TestVersionCheckScript` behavioral + `TestVersionCheckScaffold` content).
- Shared helpers: `workflow_scaffold.py` (replaces 14 private YAML loaders + the duplicated resolve-toolchain harness), `tests/nix_helpers.py` (replaces 6 `_nix_env` copies, cached `current_system`), conftest `dc_exec()` (~28 inlined argv blocks) and the extracted pexpect stage report.
- Workflow-shape files merged: `test_release_core.py`, `test_workflow_release_publish.py` (parametrized over both publish surfaces), `test_promote_release.py`, `test_vig_os_manifest.py` (11 keys + 6 outputs parametrized).
- Table-driven bats families (knob round-trips, preserve/diff-hint trios, per-mode groups, githooks matrix) with per-item failure attribution.
