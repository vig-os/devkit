# [PR 1818](https://github.com/vig-os/devkit/pull/1818) fix(just): remove test-devcontainer leftovers in clean-test-containers

## Description

`just clean-test-containers` only matched `workspace-devcontainer*` (the devcontainer fixtures). The image-test fixture `test_container` (`tests/conftest.py`) names its containers `test-devcontainer-<epoch>`, so a killed `test_image.py` run left containers the recipe never removed.

## Changes Made

- `justfile` (`clean-test-containers`): also collects `podman ps -a --filter "name=^test-devcontainer-"` and removes those containers, with its own progress line. The "[OK] / none found" summary covers both kinds.
- `tests/bats/just.bats`: two behavioral tests run the real recipe against a `podman` stub that applies `--filter name=` as a regex:
  - `test-devcontainer-*` leftovers are removed, and unrelated containers are left alone.
  - `workspace-devcontainer-*` removal still works.
