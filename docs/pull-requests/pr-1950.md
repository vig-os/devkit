# [PR 1950](https://github.com/vig-os/devkit/pull/1950) feat: add site-private leak-check hook

## Description

Add the ADR §10 default-on site leak-check hook. A clone without private patterns exits silently; configured clones scan staged changes or selected working-tree files through gitleaks and publish only file, line and rule ID.

## Changes Made

- Resolve `DEVKIT_LEAK_PATTERNS` before `.site/leak-patterns.toml`. Use merged S4's public `vig_utils.site_config.validate_patterns` and preserve its safe error messages with exit 2. The S4 ADR amendment defines the single pattern-file contract; a missing selected file is a silent no-check without fallback.
- Materialize raw blobs from the index for added, copied, modified, renamed and type-changed paths. Use Git's NUL-delimited metadata only for path selection, with no external diff or textconv; stream raw blobs through one `git cat-file --batch` process, avoiding checkout filters and per-blob process creation. Staged, filename and all-files modes then share one gitleaks directory scanner.
- Cover full index content at changed paths, including pure renames; skip deleted and untouched paths. Filename mode skips NUL-containing inputs to enforce the text-hook contract, while direct staged and all-files scans include those bytes.
- Scan selected site bindings and repository ignore files as data. Isolate gitleaks 8.30.1's automatic source-ignore loading by scanning a root `.gitleaksignore` separately; the private config remains explicit.
- Define the default-on text/symlink hook once in `nix/hooks.nix` and mirror both portable configs. Pin gitleaks in Nix-generated hooks, and publish only file, line and rule ID. Document scan boundaries, printed paths, linked worktrees and intentional exceptions.

- Pass `--` in every hook definition before filenames; reject help-looking CLI options and disable option abbreviation. Real installed-hook commits cover `-h`, `--help`, `--he` and `--all-files` filenames.
- Own private snapshots in one cleanup routine on success, findings, errors and signals. Block SIGINT/SIGTERM/SIGHUP before deleting, restore the previous mask/handlers, and honour pending signals only after deletion with a conventional exit code and no traceback. Identify unreadable pattern files and report input read/materialization errors using only safe path metadata.
- Scan symlink link text as regular snapshot content in staged, filename and all-files modes, without following targets. Select links through `types: []` plus `types_or: [text, symlink]`, clearing the hook runner's default file-only filter. Preserve raw link text, including repeated separators, and apply path rules to link names.

S4 final-round contract for S6: PR #1938 provides `vig_utils.site_config.validate_patterns(path: Path) -> None`. It folds TOML keys case-insensitively and rejects case-variant duplicates, rejects top-level extend in any case, and requires at least one usable rule with nonempty string id and regex or path. Other semantics remain with gitleaks. The single normative rule is recorded as the 2026-10-29 S4 pattern-file clarification in ADR Amendments. `.site/leak-patterns.toml` is unchanged. S6 can import this public function after S4 merges.
