# [PR 1941](https://github.com/vig-os/devkit/pull/1941) test: prevent fixture maintenance races during scaffold drift

## Description

Fixture commits can launch detached Git maintenance that removes loose objects while the scaffold-drift step clones the repository. Disable automatic maintenance in test fixture repositories before commits so those readers see stable objects.

## Changes Made

- Add one shared `disable_git_auto_maintenance` helper in `tests/conftest.py`, configuring repository-local `maintenance.auto=false` and `gc.auto=0`; document the race and prior art #1815.
- Apply it to the drift, scaffold-file walk, floating-tag remote, host-install and flake-consumer fixture repositories before commits.
- Assert both settings in the real drift fixture, preserving the clean-then-drift behavior test. No retries or sleeps.
