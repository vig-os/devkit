# [PR 1946](https://github.com/vig-os/devkit/pull/1946) feat(ci): support per-lane runner size overrides

## Description

Implement #1927: consumers can opt project lanes into larger runner classes with `DEVKIT_CI_LANE_SIZES=test=xlarge,lint=large`. Every lane continues to default to SMALL. Invalid entries and duplicate lanes fail at both scaffold time and resolution.
