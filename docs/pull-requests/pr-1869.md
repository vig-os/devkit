# [PR 1869](https://github.com/vig-os/devkit/pull/1869) feat(ci): route release-train jobs through DEVKIT_CI_RUNNER

## Description
Release-train workflows hard-coded `runs-on: ubuntu-26.04`. They now use the existing mechanism: resolve-toolchain's `runner-json` (jobs after the resolve step), `vars.DEVKIT_CI_RESOLVE_RUNNER || 'ubuntu-26.04'` (resolve jobs; prepare-release's `validate` resolves inline; standalone `publish-release-extension`). Reusable `release-core`/`release-publish`/`release-extension`/`prepare-release-extension` take an optional `runner-json` input (default hosted). Default unchanged for existing consumers.

Hosted by design (not release train): codeql, scorecard, devkit-upgrade. Sparse checkouts already use their own path (#1866).

**Compat note:** a preserved (consumer-owned) copy of the two extension hooks that predates the `runner-json` input must add it, as with `ci-extension`.
