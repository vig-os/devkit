# [PR 1726](https://github.com/vig-os/devkit/pull/1726) feat(init): insert the shellcheck-composite-actions hook into preserved configs from 1.17.0

## Description

#1718 added the scaffolded `shellcheck-composite-actions` hook, but a consumer with a preserved `.pre-commit-config.yaml` only receives a new hook through the `inserted_hook_blocks()` table in `assets/init-workspace.sh`, keyed on the first release that ships it. #1723 already put the re-check of that table on the Phase 1 prerequisites; this adds the row itself.

**Why the version can be fixed now.** `dev` holds two `feat` commits since 1.16.0 (#1718 and #1724) and no breaking change, so the next train is `1.17.0` by construction, and it is planned for Monday 2026-09-28. The only rename possible from here is upward, and an upward rename leaves a `1.17.0` row harmless: every consumer's pin is still below it at adoption, and nobody can ever sit exactly at `1.17.0`. The #1651 defect (re-adding a hook a consumer deleted) needs the row to be *below* the real first release, which would require a downward rename that a `feat` on `dev` rules out unless both are pulled — the case the #1723 prerequisite now catches on the release branch.

**Mechanism, verified rather than assumed.** Rows are `<first release> <hook> [feature group]`; `insert_missing_hook_blocks` reads `read -r ver hook feat`, so the two-field row is legal and the empty group never gates. The block comes from the rendered template structurally (the `- repo:` entry holding `- id: shellcheck-composite-actions`); the anchor derived from the template is `actionlint`, so the row must follow the actionlint row: a pre-1.16.0 tree gains actionlint first and the composite block right after it, in one pass.

**End-to-end, with the real script:** a temp workspace at `DEVKIT_VERSION=1.16.0` whose config lacks the composite block gains exactly that block after the actionlint sentinel end, nothing else changes, and a second run is byte-identical. Output: `Inserted the 'shellcheck-composite-actions' hook after 'actionlint' (shipped since 1.17.0, this tree predates it at 1.16.0, #1654).`
