# [PR 1949](https://github.com/vig-os/devkit/pull/1949) feat: migrate CI runner settings and seeded hooks safely

## Description

Devkit upgrades remove the legacy runner key only when the CI upgrade context provides valid variables for every required class. Local installs and gitflow adoptions still running an older workflow on main keep the key and report variables as unknown.

Seeded release hooks migrate historical stock runner values only with a valid SMALL variable in the CI upgrade context. Custom runners remain untouched and are reported by file and job; pending or drift findings prevent a legacy-variable deletion hint.

## Changes Made

- Forward the six migration environment names through both installer paths using one allow-list; document the environment contract in ADR §6.
- Audit hook history across all tags and dev builds. One stock constant covers the hosted 22.04/24.04/26.04 values, the intermediate input expression, and the legacy resolve-variable expression. The current SMALL expression is already reconciled.
- Preserve indentation, inline comments, CRLF/LF endings, and absent final newlines while reconciling stock values. Report customised or unclassified content explicitly.
- Send reconciled, pending and drift findings through `ci-runner-migration:`. Current workflows lift them into the migration section; pre-N workflows drop them, as ADR §6 requires, instead of mislabelling them under unrelated preserved-hook headings.
- Add `MIGRATION.md#seeded-hook-runner-migration`, correct decision (d)-1 and its amendment, and classify the feature under Added in the changelog.
