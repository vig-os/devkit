# [PR 1791](https://github.com/vig-os/devkit/pull/1791) chore(security): renew fzf CVE-2026-53432/53433 exception to 2026-11-18

## Description

Renews the fzf 0.72.0 exception block in `.vulnixignore` (CVE-2026-53432, CVE-2026-53433). It expired on 2026-10-07 and now expires on **2026-11-18**. From 2026-10-08, `check-expirations` would otherwise turn every branch, both nightly lanes and the release train red.

This is a re-verification, not just a new date:

- The pinned nixpkgs rev on `dev` and `main` (`cf5e7650`) still ships fzf 0.72.0. So do `nixos-26.05`, `release-26.05` and `staging-26.05`, all checked on 2026-09-30.
- No 26.05 backport PR is open; fzf 0.73.1+ is on unstable only. There is no newer pin to move to.
- Both findings are still live in the latest `dev` nightly (run 36705134920, `nix-image-cve-scan-dev` artifact).
- The assessment is unchanged, and both findings only affect availability. 53432 only affects 32-bit builds, and the image is 64-bit. 53433 is a denial-of-service on fzf's opt-in localhost `--listen` server.
- The block gets its own directive. Only the two fzf entries sit under it, and no other expiry date changes. 2026-11-18 is a free Wednesday slot on the expiry grid.

`main` carries the same block (#1788). It is renewed when this change reaches `main` with the next release train, which must be promoted before 2026-10-07.
