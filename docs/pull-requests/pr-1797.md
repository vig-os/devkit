# [PR 1797](https://github.com/vig-os/devkit/pull/1797) feat: CI extension seam so consumer jobs gate CI Summary

## Summary

Closes the gap where a consumer's own CI checks (clippy, a macOS matrix leg,
etc.) can only gate `CI Summary` by hand-authoring a separate workflow and a
separate required check in branch rulesets. Adds a fourth preserved,
consumer-owned seam -- `ci-extension.yml` -- alongside the three existing
release-process ones (`release-extension.yml`,
`prepare-release-extension.yml`, `publish-release-extension.yml`), following
the same shape: a no-op-by-default `workflow_call` stub the managed `ci.yml`
calls as the `extension` job, aggregated by `summary` (`CI Summary`) exactly
like every other lane.

- `ci.yml`: new `extension` job (`needs: [resolve-toolchain]`, `uses:
  ./.github/workflows/ci-extension.yml`, `secrets: inherit`, read-only
  `permissions: { contents: read, packages: read }`), passing
  `mode`/`image`/`image-tag`/`runner-json` from `resolve-toolchain`'s
  outputs. `summary.needs` gains `extension`, with a matching
  `failure`/`cancelled` block.
- New preserved stub `ci-extension.yml`: every `workflow_call` input
  `required: false`, `runs-on: ${{ fromJSON(inputs.runner-json) }}` with a
  safe default, read-only permissions, no-op default body.
- `assets/init-workspace.sh`: `ci-extension.yml` added to `PRESERVE_FILES`
  (seeded on a fresh scaffold, never overwritten on `--force`).
- `assets/smoke-test/.github/workflows/ci-extension.yml`: a real (non-empty)
  extension -- asserts the `mode` input actually arrived -- so the release
  train live-proves the seam end to end rather than leaving a future
  migration (e.g. scitadel's) as its first test.
- Docs: new "CI Extension Hook" section in `docs/DOWNSTREAM_RELEASE.md`
  (next to the three release-process hooks); `ci-extension.yml` added to the
  consumer-owned-seams list in `docs/WORKFLOW_SECURITY.md`'s Renovate
  managed-set exclusion note (already auto-derived by the drift-gated test,
  this just keeps the prose accurate). `CHANGELOG.md` `## Unreleased` ->
  `### Added`.

## Amendments honored (issue #1761, comment 5931764358)

1. **No `DEVKIT_CI_EXTENSION` knob** -- `ci.yml` calls the extension job
   unconditionally (no `if:`, no new `resolve-toolchain` output). A
   skip-by-default knob would reintroduce exactly the silent-skip failure
   this issue exists to prevent.
2. **Every `workflow_call` input is `required: false`** -- the stub is a
   preserved, consumer-owned contract; a later required input would break
   every existing copy.
3. **`runs-on` resolves from `fromJSON(inputs.runner-json)`**, never a
   literal `ubuntu-26.04` -- actionlint 1.7.12 doesn't know that label, so a
   literal fails the moment a consumer starts editing the stub.
4. **smoke-test ships a real, non-empty extension** so the seam is
   live-proven by the release train.

Permissions ceiling stays read-only (`contents: read`, `packages: read`), as
specified.
