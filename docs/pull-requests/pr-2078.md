# [PR 2078](https://github.com/vig-os/devkit/pull/2078) fix(nix): make the machine modules' agent CLI opt-in

## Description

Devkit no longer installs or pins `claude-code` through the machine-level modules unless the machine opts in. This is the follow-on to #1967, which made the same change for project dev shells. A machine's own `claude` (a native install, or a wrapper that picks a release channel and loads per-profile credentials) is no longer shadowed, and its native updater is no longer forced off.

## Type of Change

- [x] `fix` -- Bug fix

### Modifiers

- [ ] Breaking change (`!`) -- This change breaks backward compatibility

## Changes Made

- `nix/home/packages.nix`: new `vigos.packages.agentCli.enable` (default off). `home.packages` gets `devTools` always and `agentTools` only on opt-in. The opt-in also sets `DISABLE_AUTOUPDATER=1` (`mkDefault`), because Nix then owns updates.
- `nix/home/claude.nix`: no longer sets `DISABLE_AUTOUPDATER` unconditionally.
- `flake.nix` `nixosModules.default`: new `programs.vigos-devtools.agentCli.enable` (default off); the opt-in also sets `DISABLE_AUTOUPDATER=1`.
- The container image is unchanged and keeps its CLI.
- `tests/agent-cli-policy.nix`: covers both directions for home (new and legacy option names) and NixOS, asserts devTools are still present, and checks the updater variable on both surfaces.
- `tests/test_flake_checks.py`: the full ci profile expects no `DISABLE_AUTOUPDATER`.
- Docs: NIX.md (Agent CLI opt-in), an ADR amendment note, comments in `templates/personal`.

## Changelog Entry

### Changed
- **Home and NixOS modules leave the agent CLI to the machine** ([#2076](https://github.com/vig-os/devkit/issues/2076))
  - Upgrade note: machines that got `claude` from `vigos.packages.enable` or `programs.vigos-devtools.enable` must install it themselves or opt back in with `vigos.packages.agentCli.enable = true` (home-manager) or `programs.vigos-devtools.agentCli.enable = true` (NixOS).
  - Without the opt-in, a machine's own `claude` (native install, or a wrapper with its own release channel and credentials) is never shadowed by devkit's pin.
  - `DISABLE_AUTOUPDATER=1` is set only with an opt-in, where Nix owns updates; `vigos.claude` alone no longer disables the native updater.
  - The container image keeps its CLI.
