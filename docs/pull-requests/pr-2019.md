# [PR 2019](https://github.com/vig-os/devkit/pull/2019) feat(docs): add opt-in Typst content guards

## Description

Add docs-only content checks for missing figure captions, missing table headers, direct page/font overrides, and SVG lettering below 7 pt at its placed size. The shared hook supports skip globs and end-of-line suppression with source diagnostics.

## Changes Made

- Add `typst-content` through the shared docs hook definition and portable asset; keep non-docs hook configuration unchanged.
- Query compiled content once per entry in one shared ephemeral mirror, with source diagnostics and at most two compiler workers. Preserve native image values and validate a clean original compile before falling back from instrumentation failures or warnings.
- Resolve literal and variable image paths relative to their containing source and retain generated assets. Honor table suppression without derived-table duplicates, detect multiline function/closure template overrides, and scope duplicate-label/fallback suppression to individual calls in dependency/document order.
- Preserve markup and caption prose around inline expressions so grid/column measurements stay instrumented, while retaining multiline and imported closure checks.
- Attribute logos only to direct document-template parameters and measure each logo/body placement independently; dictionary keys cannot supply logo attribution. Instrument only compiler-reported dependency sources with indexed scanning, linear edit assembly, and cached dependency-edge tokenization.
- Measure SVG fit, nested SVG/symbol viewports, inherited font units, height-only sizing, visible text and used definitions. Resolve CSS font shorthand from Matplotlib 3.6–3.9 and the 3.10 font-size form with the normal cascade and `!important`; warn on unresolved sizes and bounded use expansion. Accept Matplotlib DOCTYPEs while blocking entities/external references; warn per placement for Typst scale transforms.
- Ship package 0.2.1 with guard-only layout measurements for percentages, automatic sizing, grids, columns and figure bodies. Archive the exact shipped 0.2.0 source and retain historical imports and hashes.
- Document fallback sizing, unresolved-size warnings, SVG limitations and suppression. Add a dedicated sandboxed compiler contract and a reproducible medium-document benchmark.

- Track code and markup with one structural tokenizer, including multiline else chains, smart quotes, URLs, escaped hashes and qualified builtin calls. Reuse its modes, delimiters and comments for instrumentation.
- Record effective paper, margins and font in guard-only package contexts at page starts and headings. Report runtime bypasses by page; document the entry-level runtime suppression marker.
- Warn on incomplete CSS blocks and cap selector/node work at 1,000,000, including repeated reference visits.

## Additional Notes

Relative and automatic sizing without package metadata uses the documented page-width fallback. Unresolved sizing/font shorthand, unsupported SVG styling, scale transforms and SVG use expansion limits emit named warnings. SVG traversal is capped at 32 reference levels and 32,768 visited nodes, including repeated reference contents. Unsupported uppercase font properties, declaration comments and spaced importance markers warn explicitly. Images from bytes have no inspectable source path and are documented as skipped. Raster images and lettering converted to outlines cannot be measured. Rebased onto #2017; retain the released 0.2.0 source and hash while shipping guard instrumentation in 0.2.1.

The retained 0.2.0 package is an unchanged archive of previously reviewed source from #2017. Shared defusedxml is retained so dynamically activated docs hooks and recipes always use the same hardened parser without a second Python environment; the dependency tradeoff is documented in both CHANGELOGs.
