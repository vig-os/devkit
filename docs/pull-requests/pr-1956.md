# [PR 1956](https://github.com/vig-os/devkit/pull/1956) docs: rewrite self-hosted runner migration guide

## Description

Rewrites `docs/MIGRATION.md`'s "Run CI on self-hosted runners" section to document the shipped site-agnostic runner mechanism (`CI_RUNNER_SMALL`/`LARGE`/`XLARGE` variables, the fork predicate, size classes and the `DEVKIT_CI_LANE_SIZES` lane override, and the N/N+1/N+2 deprecation timeline) in place of the stale, pre-migration `DEVKIT_CI_RUNNER`-comma-list description. Source of truth: `docs/rfcs/ADR-site-agnostic-projects.md`, cross-checked against the merged S1/S1b/S1d/S2/S3 code (`resolve-toolchain/action.yml`, `ci.yml`, `devkit-upgrade.yml`, `init-workspace.sh`).

## Changes Made

- Rewrote the variable-selection, fork-safety and deprecation-timeline content of "Run CI on self-hosted runners", replacing the removed comma-separated `DEVKIT_CI_RUNNER` mechanism and the site-specific example label/`gh variable set` value (both replaced with `<label>`)
- Added `####` subsections: Size classes and the lane override, Fork safety (including decision (f)'s remedy for forks of a private repo, and the owner-confirmed wording that the fork predicate is accident-prevention, not the security boundary), Deprecation timeline, and Known symptoms (the "CI never starts on a private repo" §3 notice limit, and the whitespace-only/malformed `CI_RUNNER_SMALL` symptom)

- Fixed one stale cross-reference to the old mechanism in the adjacent "Keep the dev-shell gcroot" section
- Left the already-correct "Seeded hook runner migration" subsection (S3, #1949) untouched, including its anchor
