# [PR 2040](https://github.com/vig-os/devkit/pull/2040) fix: realise direnv scaffold sources with flake prefetch

## Description

On Nix 2.35, metadata can report an unrealised source path, so direnv installs fail when copying assets. Use `nix flake prefetch --json <ref> | jq -er .storePath` to realise the source before reading it. Targets `release/1.19.0`.

## Changes Made

- Switch the installer fetch, dry-run plan, and consumer Scaffold Drift command/comment to prefetch. Devkit’s own CI has no equivalent source fetch.
- Model Nix 2.35 in installer stubs: metadata returns a nonexistent path, prefetch returns real assets. Pin the complete workflow and dry-run commands.
- Audit `git grep -nE 'flake metadata'`: leave freshness.sh unchanged because it reads locked input metadata only; the provisioning example does not read source files. Historical changelog text stays unchanged.
- Add the Unreleased fix and regenerate the devcontainer changelog mirror through sync_manifest; the consumer seed remains empty.
