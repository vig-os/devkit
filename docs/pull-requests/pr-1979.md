# [PR 1979](https://github.com/vig-os/devkit/pull/1979) fix(security): fix Brotli and scope its scanner exception

## Description

Ship Google Brotli 1.2.1 to fix CVE-2026-111497 and scope the remaining Vulnix false positive to that exact package/version. Vulnix 1.12.4 ignores CPE vendors: NVD's andybalholm Go-port range (below 1.2.7) also matches Google's patched 1.2.1. A CVE-wide exception would incorrectly allow vulnerable Google Brotli 1.2.0.

## Changes Made

- Keep the stable nixos-26.05 pin at 08d3a97586f6b6343b3b5e799980773629432610, shipping Brotli 1.2.1 and SQLite 3.53.3. The stable advance includes 392 upstream commits.
- Add exact `CVE@pname@version` matching to vulnix-gate while preserving existing bare-CVE entries and expiry semantics. The Brotli entry is `CVE-2026-111497@brotli@1.2.1`, reviewed 2026-11-02, due for review 2026-11-25, expiring Wednesday 2026-12-02 (30 days).
- Remove CVE-2026-11822 and CVE-2026-11824: SQLite's upstream CVE table identifies 3.53.2 as fixing both; the stable pin ships 3.53.3.
- Leave glibc entries and their expiry unchanged: policy requires re-verification on renewal, and these are not being renewed. Independently confirmed all six cited fix commits remain in the new stable pin's applied aggregate patch.
- Correct both changelogs and shorten the Nix dependency documentation; document scoped exception syntax in the security policy.

Evidence: [Google advisory, patched at 1.2.1](https://github.com/advisories/GHSA-9v8h-qqgm-4m35), [NVD CPE ranges](https://nvd.nist.gov/vuln/detail/CVE-2026-111497), [SQLite CVE fix table](https://www.sqlite.org/cves.html).
