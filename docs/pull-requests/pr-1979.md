# [PR 1979](https://github.com/vig-os/devkit/pull/1979) fix(nix): update Brotli decoder dependencies to 1.2.1

## Description

Fix CVE-2026-111497 in the 1.18.1 image dependencies. Crafted Brotli streams can reach the native decoder through shipped curl and Node.js, so this updates dependencies without adding an exception.
