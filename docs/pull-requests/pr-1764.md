# [PR 1764](https://github.com/vig-os/devkit/pull/1764) fix(renovate): cover smoke-test Python and Rust in vulnerability-fix PRs

## Summary

Closes the Renovate vulnerability-fix coverage gaps in the shipped config (vig-os/org-config#307 moves vulnerability fixes from Dependabot security updates to Renovate):

- `assets/smoke-test/renovate.json`: `enabledManagers` now `["github-actions", "pep621"]`. The smoke overlay is overwritten on every deploy, which reverted the hand fix in devkit-smoke-test#221.
- `assets/workspace/renovate.json`: adds `cargo` (a no-op where there is no `Cargo.toml`).
- `assets/workspace/.github/renovate-default.json`: new `cargo` packageRule (`build(cargo)`), placed before the managed-exclusion rule, which stays last. New explicit `vulnerabilityAlerts` block labelled `security`, placed after `lockFileMaintenance`. No `osvVulnerabilityAlerts`.
- Docs: a "Vulnerability-fix PRs" section in `docs/WORKFLOW_SECURITY.md`, and a `docs/MIGRATION.md` step for existing Rust consumers, whose preserved `renovate.json` needs `cargo` added by hand. CHANGELOG entry under `### Fixed`.

Devkit's root `renovate.json` extends the asset preset directly (there is no mirrored copy), so it picks up both changes and needs no edit.
