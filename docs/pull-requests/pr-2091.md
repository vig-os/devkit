### [`v32.0.0`](https://redirect.github.com/cachix/install-nix-action/releases/tag/v32.0.0)

[Compare Source](https://redirect.github.com/cachix/install-nix-action/compare/v31.11.5...v32.0.0)

#### Breaking changes

- Drop support for `x86_64-darwin` (Intel Macs).
  Nix no longer provides installers and binaries for this platform.
  Older Nix releases (< 2.36) can still be installed by setting `install_url`, but this action no longer tests against the platform.
