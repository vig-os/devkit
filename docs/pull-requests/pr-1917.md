# [PR 1917](https://github.com/vig-os/devkit/pull/1917) docs(rfcs): propose site-agnostic projects ADR

## Description

Proposed ADR for [#1908](https://github.com/vig-os/devkit/issues/1908): site-agnostic projects. CI runners come from the
`CI_RUNNER_SMALL` / `CI_RUNNER_LARGE` / `CI_RUNNER_XLARGE` variables with a fork predicate on every path. The legacy
`DEVKIT_CI_RUNNER` key and `DEVKIT_CI_RESOLVE_RUNNER` variable are deprecated for one release and then fail loudly. The ADR
also defines the gitignored `.site/` convention and its `site-init` hook contract, an env-only endpoint lint, a site
leak-check hook point and a going-public checklist.

Design only. There is no implementation in this PR. Status: **accepted**.

## Changes Made

- New `docs/rfcs/ADR-site-agnostic-projects.md`, structured like `ADR-publish-lanes.md`. It contains:
  - the context and the evidence from the 2026-10-25 test comment;
  - the exact `runs-on` expressions for release N and N+1, and the `runners` / `runner-sources` algorithm, covering
    comma lists, blank values and the hosted default `ubuntu-26.04`;
  - an inventory of every scaffolded job and every devkit job that selects a runner;
  - migration: per-run full-text warnings as the primary channel, the migrating adoption (first ≥N `devkit-upgrade.yml` run from the default branch) as cleanup, an N+2 tombstone gated on the consumer's own variables, and the PR-body text;
  - the security analysis: fork PRs, `pull_request_target`, `workflow_run`, reusable cross-repo calls, and why the
    explicit check stays;
  - the `.site/` schema, the site-init hook, the lint and the leak-check contracts;
  - the Decisions section, which records the owner's choices and the rejected options;
  - ordered implementation sub-issues S1, S1d, S1b, S2–S7, S7b, S8, S9 with file overlaps and merge order, which the architect files.
