# [PR 1992](https://github.com/vig-os/devkit/pull/1992) fix(ci): recover promotion of manually merged release PRs

## Description

Recover `promote-release` when an approved release PR was merged manually and its branch deleted. Both devkit gates prefer an open PR, then accept exactly one merged PR only after verifying approval and that its merge commit and release tag are ancestors of main. Recovery works when dispatched from main or dev.

## Type of Change

- [x] `fix` -- Bug fix

### Modifiers

- [ ] Breaking change (`!`) -- This change breaks backward compatibility

## Changes Made

- Share the PR lookup and merged recovery checks between validate and merge.
- Require an approval on the final head when merged PR reviewDecision is empty.
- Skip mergeability and pending checks for merged PRs; retain failed and successful CI checks and all other validation.
- Skip the completed merge while keeping merge success and cleanup scheduling.
- Document recovery, including the instruction to avoid manual release PR merges.
- Scope workflow changes to devkit; consumer gates retain their separate protection-aware behavior.
