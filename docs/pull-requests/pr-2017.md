# [PR 2017](https://github.com/vig-os/devkit/pull/2017) feat(docs): add offline plots glossary helpers and slides

## Description

Add `@local/devkit-docs:0.2.0` with offline native plots, consumer-loaded glossary rendering, and a 16:9 presentation layout. Preserve byte-identical 0.1.0 and 0.1.1 imports and their content hashes.

Glossaries load explicitly with `#show: glossary-setup.with(yaml("/glossary.yaml"))`. This works with large registers, plain compilation, editor previews, hooks, and recipes without transporting YAML through compiler arguments. Acronyms expand at their first body occurrence; outline and figure-outline copies use short forms. For PDF bookmarks, `glossary-tools` binds canonical term text before layout while retaining contextual expansion. The legacy setup API remains supported; bookmark-safe headings use the documented bound `term` helper.

## Changes Made

- Vendor lilaq 0.5.0 and its complete licensed, content-locked dependency closure.
- Require both plot axis labels and a figure caption. Keep ordinary labels and ticks at 9 pt, synthesized super/sub text at 7 pt, and attached math scripts at least 7 pt. Reject explicit undersized math text; document limits for arbitrary user math and transforms.
- Load glossary data in the consumer's filesystem scope, reject duplicate IDs while building the lookup dictionary, diagnose missing registers and unknown IDs, and render a sorted, unique used-term appendix.
- Resolve YAML exponent and octal scalars before the existing string-only schema validation, so numeric spellings cannot pass as terms, aliases, or forbidden names.
- Add title, section, and content slides with shared branding, type scale, booktabs, captions, and revision stamps. Footer text comes from `short-title` or `title`, extracted read-only with an explicit work stack, without recursive traversal, reconstruction or source-element layout. Hidden content is omitted, term items retain their term and description, paired single/double smart quotes remain readable, and cells, nonzero horizontal spacing and math attachments separate text leaves. Render plain text at 9 pt on one fixed line, truncate measured grapheme prefixes with a logical-end ellipsis, align to the text direction, and reserve a 2 mm counter gap. Bound extraction to 400 graphemes and a one-million-item for-loop traversal budget; handle apostrophes after letters/digits, separate cases and vertical spacing, and document same-type nested double-quote limits. Skip footnotes and placed content; document plain-text and unknown-atom behavior.
- Exercise both footer sources across styled text, math operators, block containers, labelled content, footnotes, transformations, breaks, tall images, Hebrew, CJK, emoji and long words. Supply a licensed two-character CJK font fixture for deterministic offline PDF extraction.
- Force synthesized plot super/sub glyphs at 7 pt, give missing/empty registers clear diagnostics linked to current public docs, and document footnote-first expansion, outline show-rule ordering, and explicitly styled math-attachment limits. Reject empty YAML and empty arrays in both compilation and schema validation; lead the README with the bound glossary API.
- Extend real compiler/PDF acceptance checks, including a register over 150 KB through the actual compile hook, canonical recipe, and plain compiler.
